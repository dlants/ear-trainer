# isolated audiation exercises?

"sing a 3" is kind of a weird exercise right? Like... sing a 3 in isolation? That's pretty odd...

I'm trying to think about what are the contextualized, performance-oriented things that look like "audiate a 3" ...

I can see "know what voicing out a triad would sound like" ... or like... if you're improvising?

I can see... harmonize above this note with a 3...

Maybe sight-signing... but is sight-signing a goal in and of itself for many musicians? I guess maybe if you're using written notation a lot and are expected to play off of written notation, but I wonder how relevant that is to a hobbyist like me.

I guess I only really care about sight-signing if it is relevant to my goals - being able to hear a bit of music, hear what is happening there, and be able to then follow along or contribute something novel.
